# README media

This directory contains the media used by [README.md](../../README.md) and
[README_ZH.md](../../README_ZH.md). Both READMEs reference the same media set, so
the two language versions never hold duplicate images.

Current assets:

- `demo.gif` — inline README demo
- `demo.mp4` — higher-quality recording
- `orb.png` — Floating collapsed to the Orb
- `sidebar.png` — Sidebar docked to a screen edge
- `desktop.png` — Desktop mode hosted on the desktop

Reference these files from both READMEs with a repository-relative path
(`docs/assets/<file>`), never an absolute or hosted URL. If a new asset is added,
add it to both READMEs and to this list.
