# README media

Shared screenshots and recordings for the front-page READMEs. Both
[README.md](../../README.md) and [README_ZH.md](../../README_ZH.md) reference this
one directory, so the two language versions never hold duplicate images.

## Expected files

| File | Shows |
| --- | --- |
| `floating-acrylic.png` | Floating (expanded) with native Acrylic, Enhanced backend |
| `orb.png` | Floating collapsed to the Orb |
| `sidebar.png` | Sidebar docked to a screen edge |
| `desktop.png` | Desktop mode hosted on the desktop |
| `demo.gif` | Short loop: switch modes, collapse/expand the Orb, add a task |

## Conventions

- Reference these files from both READMEs with a repository-relative path
  (`docs/assets/<file>`), never an absolute or hosted URL.
- Capture on Windows 11 at a consistent display scale, and keep the widget in the
  same state in both language versions. The READMEs share one media set, so a
  screenshot that only matches one language's wording should be avoided.
- Avoid showing real task text, profile identity, weather locations, Quick Link
  URLs, or file paths. Use placeholder content for captures.
- Prefer PNG for stills and a short, silently-looping GIF or WebM for the demo.
  Keep the total size reasonable; these files are served from the repository.
